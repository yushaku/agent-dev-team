Skill

Skill là bộ hướng dẫn mà agent nạp khi cần. Đội có 4 skill tự viết và 24 skill tải về, ghim phiên bản trong skills-lock.json.

Skill do đội viết

SkillDùng khiNguồn
init-teamChạy /init-team hoặc repo chưa có .team/config.yaml. Đọc repo, hỏi PO từng câu một, ghi config. Xem Cấu hìnhskills/init-team/SKILL.md
orchestratorChạy /orchestrator hoặc nhờ "act as Orchestrator". Điều phối đội qua Orca. Các bước chi tiết nằm trong references/skills/orchestrator/SKILL.md
anti-aiTrước PR hoặc tin nhắn gửi ra ngoài. Gỡ dấu hiệu văn AI khỏi diff, docs, commit và bản nháp; không đổi hành viskills/anti-ai/SKILL.md
frappe-docsViết tài liệu hệ thống hoặc sơ đồ. Điền template HTML dạng tab, mọi sơ đồ đi qua archifyskills/frappe-docs/SKILL.md
