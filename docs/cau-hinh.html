Cấu hình

Mỗi dự án có một file .team/config.yaml chứa chi tiết riêng: tracker, branch, lệnh verify, quy tắc UI, giới hạn đồng thời. Quy trình chung không chứa stack hay tên lệnh. Chạy /init-team để tạo file này.

Tạo config: /init-team

  1. Đọc repo, không đoán: worktree_links (các file .env chưa theo dõi), branches (từ PR gần đây và workflow deploy), commands.verify (từ package.json, Makefile, README), skills.project, slot theo nền tảng, human_only (merge, deploy, migration trên DB chung, cấu hình thanh toán, secrets).
  2. Hỏi PO từng câu một, chỉ những gì repo không trả lời được: ngôn ngữ, delivery.mode, tracker, human_only, compliance, ui_rules.gate, agent cần tắt.
  3. Ghi file: chỉ các key khác mặc định, cộng skills và commands.verify. Config đã có thì hiện bảng khác biệt và chỉ đổi giá trị cũ khi PO đồng ý. Không bao giờ commit.

Slot skill

Có 8 slot: design, architecture, build.ui, build.core, qa, review, security, perf. Giá trị lấy từ skills.<slot> của dự án; slot rỗng thì chỉ dùng skill lõi của role. Slot trỏ tới skill chưa cài: báo PO một lần, không bỏ qua lặng lẽ.

Cài đặt mô hình

  • Id model, tier và effort nằm ở skills/orchestrator/references/coding-agents.md, mục "Model tiers". Cách chọn agent cho từng Task: mục "Routing".
  • models.agents.<agent>: off loại agent khỏi routing; Task của nó chuyển cho agent hợp lệ kế tiếp.
  • Thứ tự ưu tiên: leo thang > quy tắc kích cỡ trong thẻ role > models.roles > mặc định của role.

Giá trị khởi đầu theo nền tảng

Chỉ init-team dùng, rồi ghi vào config của dự án và từ đó config sở hữu. Có hai nền tảng: web (slot cho design, UI, backend, QA, perf; viewport desktop và mobile; chụp ảnh bật) và apple (iOS, iPadOS, macOS: Instruments cho perf, commands.serial: true, ưu tiên một Builder mỗi lần). Nền tảng khác: slot rỗng. Danh sách đầy đủ trong config.md.

Quy tắc tìm config

  • Tìm .team/config.yaml trong checkout chính, rồi tới giá trị mặc định.
  • Cục bộ khi thử: /.team trong .git/info/exclude. Không sửa AGENTS.md hay .gitignore vì việc này, không commit hay push file của đội. Khi chia sẻ: chỉ commit .team/config.yaml.
  • Worker không đọc config.yaml: Orchestrator đưa phần cần thiết vào spec của Task.
  • Quy tắc trong AGENTS.md hoặc CLAUDE.md của repo thắng; config chỉ ánh xạ chúng sang thiết lập của đội.

Nguồn: config.md, skills/init-team/SKILL.md, skills/orchestrator/references/coding-agents.md.

Trang này tóm tắt cho người đọc (Product Owner). Quy tắc đầy đủ nằm trong các file .md tiếng Anh của repo; nếu khác nhau thì .md đúng.
