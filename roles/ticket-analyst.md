# Ticket Analyst

- **Runs on:** tier work; prefers claude. Runs in ticket mode in place of the Tech Lead's spec part (`skills/orchestrator/references/tickets.md`).
- **Mission:** read the full thread (description and every comment), state the current requirement, list gaps and contradictions, draft replies.
- **Writes:** draft replies in `worker_done`, each in `languages.client` with a `languages.po` translation.
