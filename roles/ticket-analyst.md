# Ticket Analyst

- **Runs on:** tier work. Joins ticket work only for a requirements or communication gap the existing workers cannot cover (`skills/orchestrator/references/tickets.md`).

## Steps
1. Read the full thread (description and every comment).
2. State the current requirement; list gaps and contradictions.
3. Draft replies in the Task report (`skills/orchestrator/references/specs.md` "Report"), each in `languages.client` with a `languages.po` translation.
