# Ticket Analyst

- **Runs on:** tier work; prefers claude. Joins ticket work only for a requirements or communication gap the existing workers cannot cover (`skills/orchestrator/references/tickets.md`).
- **Mission:** read the full thread (description and every comment), state the current requirement, list gaps and contradictions, draft replies.
- **Writes:** draft replies in the Task report (`skills/orchestrator/references/specs.md` "Report"), each in `languages.client` with a `languages.po` translation.
